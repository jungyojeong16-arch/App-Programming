# 취향지도 중간발표 대본

- 발표 시간: 약 3분 30초 (제한 1~5분)
- 장표: 3장 (`01_주제_문제.png`, `02_핵심가치1_귀차니즘제로.png`, `03_핵심가치2_콜드스타트.png`)
- 표시: **[화면 손짓]** = 해당 폰 화면을 가리키며 말하기, `/` = 짧게 쉬기

## 장표 1. 주제와 문제 (약 1분 10초)

안녕하세요, **[이름]**입니다. /
제가 만들 앱은 **"취향지도"**, 사람마다 다른 취향에 맞춰 음식점과 카페를 추천해 주는 앱입니다.

**[1번 화면 손짓]**
지금 지도 앱에서 "카페"를 검색하면 이런 화면이 나옵니다.
위에는 광고가 있고, 그 아래는 별점과 리뷰 수 순서입니다.
그래서 누가 검색해도 1위가 똑같습니다. /
하지만 별점 4.5는 "많은 사람이 무난하게 만족한 곳"일 뿐, **나에게 맞는 곳**이라는 뜻은 아닙니다.

**[2번 화면 손짓]**
같은 동네에서 조용히 공부할 카페를 찾는 준호에게는,
콘센트가 많고 조용한 **카페 A**가 일치도 95%로 1위에 나옵니다.

**[3번 화면 손짓]**
반면 데이트할 카페를 찾는 서연에게는, 인테리어가 예쁜 **카페 B**가 1위입니다.
이 카페 B는 준호에게는 63%로 아래에 있습니다. /
**같은 동네, 다른 취향, 다른 1위.** 이것이 이 앱의 주제입니다.

> 강조: 화면 2·3의 "1위" 카드와 "카페 B 63%"를 번갈아 가리키기

## 장표 2. 핵심가치 ① 귀차니즘 제로, 게임처럼 (약 1분 10초)

그런데 교수님께서 짚어 주신 것처럼, 사람들은 귀찮아서 **별점 주기 정도가 최대 행동**입니다.
그래서 이 앱의 핵심가치는 **"별점보다 가볍게, 게임처럼 취향이 쌓이는 것"**입니다.

**[1번 화면 손짓]**
처음 시작할 때 긴 설문 대신 **취향 월드컵**을 합니다.
"조용한 북카페 vs 감성 루프탑" 중 하나를 탭하기만 하면 되고, 30초면 끝납니다.

**[2번 화면 손짓]**
그러면 "조용한 디저트 탐험가" 같은 **취향 유형 결과**가 나옵니다.
MBTI 결과처럼 인스타 스토리에 공유하고, 친구와 **취향 궁합**도 볼 수 있어서
앱이 자연스럽게 퍼지게 됩니다.

**[3번 화면 손짓]**
그리고 가게에 다녀오면 이렇게 알림이 옵니다. "카페 A 어땠어요?"
**앱을 열 필요도 없이 알림에서 한 번만 누르면** 피드백이 끝납니다.
별점보다도 가벼운 행동입니다. /
점심시간 전에는 "오늘 점심 추천 3곳"이 먼저 찾아옵니다.

## 장표 3. 핵심가치 ② 데이터 없이 시작, 쓸수록 정확 (약 1분)

두 번째 고민은 **초반에 데이터가 없을 때**입니다.

**[1번 화면 손짓]**
처음 쓰는 사람에게는 **자주 가는 가게 3곳만** 고르게 합니다.
고른 가게들의 특징, 예를 들어 조용함이나 가격대로 그 사람의 취향을 바로 알아내서
**첫날부터 맞춤 추천**이 가능합니다.
그리고 이 방식은 다른 사용자 데이터가 필요 없어서, **사용자가 한 명이어도 작동**합니다.

**[2번 화면 손짓]**
추천마다 **왜 추천했는지** 이유를 보여주고,
**광고와 평균 별점은 순위에 넣지 않습니다.**
여기서 누른 "좋아요"나 "내 스타일 아님"은 제 취향도 바꾸고, 가게 정보도 더 정확하게 만듭니다.

**[3번 화면 손짓]**
그래서 쓸수록 **취향 정확도**가 올라가고,
다녀온 가게는 **맛집 도감**에 모여 배지를 얻는 재미도 있습니다.

## 마무리 (약 10초)

정리하면, 취향지도는 **광고가 아닌 내 취향으로**,
**별점보다 가볍게**, **쓸수록 더 나답게** 추천하는 앱입니다.
감사합니다.

## 예상 질문과 답변

| 질문 | 답변 |
| --- | --- |
| 가게의 "조용함" 같은 정보는 어디서 얻나요? | 처음에는 학교 주변 30곳을 직접 조사합니다. 이후에는 사용자의 원탭 피드백("시끄러웠어요"), 점주 등록, 리뷰 분석으로 채웁니다. 프랜차이즈는 한 지점을 조사하면 전 지점에 적용할 수 있습니다. |
| 추천 점수는 어떻게 계산하나요? | 취향과 가게 특징을 12개 항목 점수로 만들고 둘이 얼마나 비슷한지 계산합니다(코사인 유사도). 예를 들어 준호에게 카페 A는 95%, 카페 B는 63%가 나옵니다. |
| 광고 없이 어떻게 돈을 버나요? | 순위는 팔지 않습니다. 대신 함께 고르기 같은 프리미엄 구독, 점주용 익명 통계, 예약·배달 연결 수수료를 검토합니다. |
| 같은 곳만 계속 추천되지 않나요? | 추천 10개 중 1~2개는 평소 안 가본 유형을 일부러 섞습니다. |
| 위치 정보가 걱정됩니다. | 동의한 경우에만 쓰고, 이동 기록은 저장하지 않습니다. 동의하지 않아도 추천은 동작합니다. |
