# 결 (Gyeol): 나와 결이 맞는 사람들의 리뷰로 찾는 음식점·카페

> 광고도, 평균 별점도 아닌 **나와 취향이 비슷한 사람들이 직접 가 보고 남긴 별점**으로 추천합니다.

앱 프로그래밍 수업 아이디어의 **프로토타입**입니다. 서버 없이 앱 안의 예시 데이터로 동작합니다.
외부 패키지 없이 플러터 기본 기능(`ChangeNotifier`, `ListenableBuilder`, `setState`)만 사용합니다.

## 왜 필요한가요?

| | 기존 앱 | 결 |
|---|---|---|
| 추천 기준 | 광고, 모든 사람의 평균 별점 | 나와 취향이 비슷한 사람들의 별점 |
| 사람 적고 미니멀한 곳을 좋아하는 나에게 | 북적이는 핫플이 1위 | 조용한 카페가 1위 |

같은 가게라도 **누가 평가했는지**에 따라 의미가 다릅니다.
예를 들어 `카페 여백`은 전체 평점이 ★3.8이지만, 조용한 곳을 좋아하는 사람들만 보면 ★4.8입니다.

## 기능

1. **취향 설정**: 슬라이더 5개로 취향 고르기 (한적함↔북적임, 미니멀↔화려함, 가성비↔분위기, 조용함↔활기참, 혼자↔여럿이)
2. **맞춤 추천 목록**: 가게마다 `취향 98%` 배지, **비슷한 사람 평점과 전체 평점을 나란히** 표시
3. **정렬 비교**: [취향 맞춤순] ↔ [전체 평점순]을 바꾸면 순위가 완전히 달라짐
4. **카테고리**: 전체 / 카페 / 식당 / 술집
5. **가게 상세**: 평점 비교 카드, 분위기 비교(이 가게 vs 내 취향), 리뷰마다 `나와 90%` 일치도 표시, "나와 비슷한 사람만" 필터
6. **리뷰 쓰기**: 별점 + 코멘트. 리뷰에 내 취향이 함께 저장됨
7. **취향 수정**: 오른쪽 위 버튼. 바꾸면 추천이 바로 다시 계산됨


## 추천은 어떻게 계산하나요?

### 1. 취향 일치도
취향을 5개 축 × 1~5점으로 표현하고, 축마다 점수 차이를 더합니다.

```
나      (1, 1, 4, 1, 1)
상대    (1, 1, 3, 2, 1)
차이     0 + 0 + 1 + 1 + 0 = 2        가장 많이 다를 때 = 5축 × 4점 = 20
일치도 = (1 - 2 / 20) × 100 = 90%
```

**일치도 75% 이상**인 사람을 "나와 비슷한 사람"으로 봅니다.

### 2. 추천 점수
```
분위기 일치도      = 내 취향 ↔ 가게 분위기 일치도 (0~100)
비슷한 사람 평점   = 비슷한 사람들의 별점 평균 × 20 (100점 만점으로)

비슷한 사람 리뷰가 있으면 → (분위기 일치도 + 비슷한 사람 평점) ÷ 2
아직 없으면             → 분위기 일치도만 사용
```

두 번째 경우는 **처음엔 리뷰가 부족한 문제(콜드 스타트)**를 해결합니다.
새로 생긴 `카페 틈`은 비슷한 사람 리뷰가 없지만 분위기가 잘 맞아서 추천 목록 위쪽에 나옵니다.

## 시연 시나리오 (발표용)

1. 처음 화면에서 슬라이더를 **한적함 · 미니멀 · 분위기 · 조용함 · 혼자** 쪽으로 옮기고 [추천 받기]
2. 1위 `카페 여백`: **비슷한 사람 ★4.8 / 전체 ★3.8**
3. [전체 평점순]을 누르면 1위가 `플라워가든`(사람 많은 핫플)으로 바뀜. 기존 앱의 방식
4. 다시 [취향 맞춤순] → `플라워가든`을 눌러 보면 비슷한 사람 평점은 ★2.5
5. [취향 수정]에서 북적임 · 화려함 쪽으로 바꾸면 1위가 `루프탑 노을`로 바뀜
6. `카페 틈`에 리뷰를 남기면 "비슷한 취향 리뷰 없음"이 "비슷한 사람 ★5.0 (1명)"으로 바뀜

## 다음 단계 (프로토타입에 없는 것)

- **저장**: 지금은 앱을 끄면 새 리뷰와 취향이 사라집니다. `shared_preferences`나 Firebase를 `TasteStore`에 붙이면 됩니다. 화면 코드는 고칠 필요가 없습니다.
- **로그인과 서버**: 실제 사용자들의 리뷰를 모으려면 필요합니다.
- **리뷰로 가게 분위기 정하기**: 지금은 가게 분위기를 예시 데이터에 직접 적었습니다. 리뷰를 쓸 때 "혼잡도, 인테리어…"를 함께 입력받아 평균을 내면 됩니다.
- **지도, 방문 인증**(영수증·위치)으로 가짜 리뷰 막기
- **상황별 취향**: "혼자 갈 때 / 친구랑 갈 때" 취향을 따로 두기
